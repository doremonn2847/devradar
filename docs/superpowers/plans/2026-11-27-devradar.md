# DevRadar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows background worker that reads Claude Code/Codex session files, tracks per-project progress, raises "something's off" alerts and gathers tech news, and exposes it all as MCP tools to a Hermes Agent that talks to the user on Telegram via DeepSeek Flash.

**Architecture:** A pure-Python worker (collector → distiller → project-state LLM update → rules → news) writes to one SQLite file. An MCP server reads/writes that file and gives Hermes its tools. Hermes owns Telegram, the 07:30/21:30 cron jobs and replies; the worker wakes Hermes only when a new alert exists.

**Tech Stack:** Python 3.12, stdlib `sqlite3`, `pyyaml`, `httpx`, `openai` (OpenAI-compatible client for DeepSeek), `mcp` (FastMCP), `apscheduler` 3.x, `pytest`, `respx` (httpx mocking). Hermes Agent (installed separately). PowerShell for Windows Task Scheduler.

**Spec:** `docs/superpowers/specs/2026-11-27-devradar-design.md`

## Global Constraints

- Platform: Windows, laptop only; all paths via `pathlib`, never hard-coded `/`. Files read/written as UTF-8.
- Session roots: `%USERPROFILE%\.claude\projects` and `%USERPROFILE%\.codex\sessions` (overridable in `config.yaml`).
- LLM: model `deepseek-flash`, base URL `https://api.deepseek.com`, key from env `DEEPSEEK_API_KEY`.
- DeepSeek prices per 1M tokens — off-peak: cache hit $0.003, miss $0.15, output $0.6; peak: $0.006 / $0.3 / $1.2. Peak = UTC 01:00–04:00 and 06:00–10:00, Mon–Fri.
- Soft cost cap: $6/month (config `cost.soft_cap_usd`). Past it: no LLM calls from the worker.
- Timezone `Asia/Bangkok`. Collector every 20 min. Session "finished" after 30 min with no new lines. Recap 21:30, radar 07:30 (Hermes cron).
- Excerpt cap ~4,000 tokens (estimate tokens as `len(text) // 4`).
- Rule defaults: stalled N=3 days; deadline drift ≤14 days away and N=2 days idle; loop ≥3 sessions in 7 days; dangling 24 h; spread thin ≥4 active projects in 3 days with no new "done". Cooldown 3 days per (rule, project).
- News: dedupe window 14 days; store top 30 candidates.
- No raw transcript text leaves the machine except distilled excerpts sent to DeepSeek.

## Review Focus

1. **A session file is mid-write** (last line has no trailing newline) → that partial line is not parsed or skipped forever; it is read on the next pass. *(Task 2)*
2. **A session file shrinks or is replaced** (size < stored offset) → offset resets to 0 and the file is re-read, no crash. *(Task 2)*
3. **The session's cwd no longer exists or isn't a git repo** (deleted Orca worktree) → falls back to the normalized cwd as project key; never raises. *(Task 3)*
4. **DeepSeek returns broken JSON, or "done" items citing session ids it was never given** → retry once, then keep the old state; uncited/foreign-cited done items are dropped. *(Task 5)*
5. **Unicode paths and text** (Vietnamese folder names, Vietnamese prompts) → parsed, stored and returned intact. *(Tasks 2 and 3)*
